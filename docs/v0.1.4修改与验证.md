# HowDoI v0.1.4 修改与验证

日期：2026-10-15。版本：`0.1.4+5`，唯一来源为 `pubspec.yaml`。本轮只修改 Windows 删除提示、侧栏按钮间距和预计预算；安卓、SPSir、实际开支继续暂缓。

## 修改内容

### 删除提示

当前 Flutter 的 SnackBar 带 action 时默认 `persist=true`，仅设置 duration 不会超时。删除空白日的提示显式设置 `persist=false` 和 7 秒时长；显示新提示前清空队列并移除当前提示。撤销立即关闭提示，只恢复该提示对应的日期。

没有增加延迟删除或数据修改定时器。提示到期只关闭撤销入口，删除已经在用户操作时完成。空白日期判定、非空日期二次确认、关联日期保护与日期排序代码不变。

### 侧栏间距

移除创建旅行与添加日期之间额外的 20px 分组间隔，并关闭这两个按钮默认的额外触控留白。保留每个按钮上下各 6px 外边距，视觉间距为 12px；两者保持相同宽度、42px 最小高度、12px 圆角及左对齐图标文字。没有添加分隔装饰。

### 原币种预算

- 总计按币种分别累计，分类小计按“分类→币种”累计，不生成跨币种总金额，不读取默认币种或汇率参与统计。
- 使用原有精确整数金额算法与各币种小数位规则，JPY 无小数，CNY/EUR 等保留相应小数位。金额 0 显示为零费用；金额为空计为未估算，不虚构为零。
- 仅显示有已填写金额（包括 0）的币种/分类；没有已填写金额时显示空状态。未安排历史记录仍计入预算，跨日住宿不重复计算。
- 旅行设置改为“默认预算币种”，仅预选新增费用的币种，用户可切换。编辑原费用保留其币种；修改默认值不写入任何历史费用。
- 移除手动汇率表单。旧 `rates` 字段保存时原样保留，旧 `base` 字段继续保存默认币种，不更名、不迁移。备份协议仍为 3，格式 1/2/3 正常导入。没有添加依赖或实际开支能力。
