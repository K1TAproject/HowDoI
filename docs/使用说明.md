# HowDoI 0.1.0 使用说明

## 安装与数据

Windows：解压 `dist/HowDoI-0.1.0-windows-x64.zip`，保留全部文件，双击 `howdoi.exe`。不要单独移动 exe；程序数据保存在当前用户的应用数据目录，不在解压目录。

Android：使用 `dist/HowDoI-0.1.0-android-arm64.apk`，适配 ARM64 手机。系统可能要求允许当前文件管理器安装应用。尚无商店发布或自动更新功能。

程序首次启动为空，不会装入预览用的示例旅行。输入在点击“保存行程”或旅行设置的“保存”后落盘；完成勾选和拖动排序立即保存。

## 制作路书

1. 创建旅行，填写名称和天数。出发日期可以留空；主币种默认人民币。
2. 在“待安排”中收集地点，也可以直接在某一天添加行程。
3. 选择活动类型，填写名称。航班、铁路、住宿等会显示各自详细信息，未预订的信息可以留空。
4. 电脑拖动卡片手柄排序，手机长按卡片拖动。手机左上角菜单切换旅行和日期。
5. 交通可以独立记录，也可以关联前后地点。多段交通按顺序添加；原前后地点被删除、移动或隔开时会提示确认，不删除航班号等预订信息。
6. 多晚住宿填写入住日、退房日与整段费用。一条住宿会显示在相关日期，但预算只统计一次。

日期采用 `YYYY-MM-DD`，时间采用当地 `HH:mm`。未填写固定日期时跟随旅行日；已有具体预订且旅行日期已确定时，保存会固定起止日期。之后改变出发日期，程序保留这些固定日期并提示不一致。

当天可以设置默认时区，也可为活动起止时间分别选时区。时区用城市英文名搜索，例如 Shanghai、Helsinki。跨日活动的结束默认时区取结束日。点击“检查时间与时长”检查跨时区时长；夏令时重复时刻需选择较早或较晚，不存在的时刻需修正。警告不阻止保存规划草稿。

## 预算

每项活动可以添加多笔预计费用。金额留空表示未估算，0 表示免费。费用分类固定为交通、住宿、餐饮、门票/活动、购物和其他。

旅行设置中的汇率含义：1 单位外币等于多少主币种。预算页显示已折算总额、分类小计、待折算币种和未估算数量。没有汇率的金额不计入已折算总额。待安排活动也纳入预算。

本版只做预计费用，不记录实际支出、不连接 SPSir；原接口设计文档保留作后续参考。

## 电脑与手机同步

1. 电脑和手机连接同一可信 Wi-Fi，或由手机开热点供电脑连接；两端打开 HowDoI。
2. 电脑点击同步图标，生成配对文本。将完整文本安全传到自己的手机，手机在同一页面粘贴并配对。
3. 文本包含电脑地址、证书指纹和连接凭据；不要公开或上传到仓库。撤销配对会使旧文本失效。
4. 配对后应用在前台每 10 秒尝试双向同步，重新打开/切回时也尝试连接；离线时照常保存。
5. 电脑地址变化时会尝试局域网自动发现。发现失败可重新生成配对文本，或将文本的 host 改为电脑当前局域网 IPv4 地址。
6. 仅在双端完成确认后显示“已同步”。连接失败不会删除本地数据。

网络要求：电脑 TCP 47821 用于 TLS 同步，UDP 47822 用于设备发现。Windows 防火墙如询问，应只允许应用访问可信专用网络；不要关闭防火墙。酒店 Wi-Fi 可能隔离设备，可尝试个人热点。

数据规则：不同记录的修改分别保留；同一记录按修改时间取较新版本；删除会同步。两端时间相差超过五分钟时会拒绝本次同步并提示校准。编辑表单打开后若记录已改变，重新打开表单再保存。

限制：不跨公网、不后台常驻、不支持多人权限；第一版针对一台电脑与一台安卓手机。配对文本方式优先保证可验证的设备身份，尚无扫码配对。

## 备份与恢复

右上角菜单可导出本次或全部旅行的 JSON 备份，也可导入备份。导入会先显示旅行数量，再创建新副本；不覆盖现有行程、不导入配对凭据。原备份可以手动保存到百度网盘。

旅行和活动删除会同步，请按需要先导出备份。本版没有回收站或旧版本历史。
