# HowDoI v0.1.3：Windows UI 与交互优化

交付日期：2026-10-15。版本唯一来源：`pubspec.yaml` 的 `0.1.3+4`。安卓适配、SPSir 接入、实际开支继续暂缓，原 SPSir 接口文档未修改。

## 修改内容

- 旅行和日期导航统一 12px 圆角、间距、低饱和黑蓝选中背景、悬停与键盘焦点；选中卡片带勾选标识。创建旅行与添加日期使用相同次要按钮。
- 两类卡片常驻“⋯”。旅行菜单提供编辑、导出、删除；日期菜单提供调整、删除。操作绑定对应卡片，不因为打开菜单而切换选择。移除顶部重复旅行设置和单次旅行菜单，顶部保留全局功能。
- 日期主标题优先显示月日和星期，副标题始终包含第几天与年份，跨年清晰。未定出发日期仍显示第 N 天。
- 空白日期直接删除，提供 7 秒撤销；不压缩编号，不改变其他真实日期。删除当前日后选相邻日，全部删除后回到空状态。
- 非空日默认移往另一日，目标已有记录时显示合并提示，沿用已有排序规则。也可选择删除当天开始的记录及日期，列出影响后再次确认。
- 按用户确认的规则，住宿覆盖、跨日到达等关联日不能视为空白日，须先调整关联原行程才能删除。日期调整只移动当天开始的记录，其他日期开始的关联记录保留并明确说明。移动后仍覆盖原日时，不能通过“移往另一日后删除”隐藏该日。
- 移动保留记录 ID、预算、完成状态和补充字段；开始/结束旅行日整体平移。已预订票面日期不变并提示核对，未预订固定日期随规划调整。操作预览后若发生其他编辑或同步，拒绝过期操作；验证全部变更后一次事务提交，避免半完成。
- 日期字段整块可点，日历局限于编辑区域，自动向上或在区域内展开。已有值优先，无值定位当前旅行日；月份按钮打开区域内网格，年份使用日历年选择。选一天即写草稿并收起。
- 时间使用并排滚动时/分列，支持点击、滚轮、方向键和任意分钟。一次“完成”写入草稿；取消/Esc 不改变原值，打开空字段不写入 00:00。预计时长独立处理，超过 24 小时及已有更长时长可保留。
- 滚动编辑区域、窗口尺寸变化时关闭悬浮选择器。宽窗口缩到窄窗口再放大，草稿仍在。保存行程才持久化；切换和原生关闭窗口均检查行程未保存内容。
- 标题栏使用与顶部相同的背景、文字色，取消显眼边框；保留 Windows 原生非客户区、系统按钮和窗口消息处理，不实现自绘无边框窗口。应用按钮在客户区，不作为拖动区。

## 实现边界与兼容

未改 SQLite 表结构，备份/同步协议保持 3，保留旧字段、迁移快照、兼容读取、导入重映射和更新失败恢复。没有添加依赖。预算仍只记录预计费用。原图标继续使用。

日期批量操作只更新受影响记录及排序，其他日期不自动移动。移动酒店时，其自身住宿覆盖随入住/结束旅行日整体移动；这不等于移动其他日期开始的独立行程。删除当天开始的跨日记录会删除该记录的全部关联显示，预览和二次确认中说明这一点。

Windows 标题栏颜色基于微软 [DWM 窗口属性](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)，使用原生窗口框架保留交互。日期时间交互参考 [CalendarDatePicker](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/calendar-date-picker) 与 [TimePicker](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/time-picker)，实际实现为 Flutter 组件，不宣称直接嵌入 WinUI 控件。
