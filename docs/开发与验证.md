## 开发范围

HowDoI 0.1.0 使用 Flutter / Dart，共用 Windows 与 Android 界面和业务代码；SQLite 保存记录和本机设置。SPSir 接口需求保持原文，不实现跨应用记账。

模块：

- `lib/model.dart`：数据校验、精确金额、预算、时区转换。
- `lib/store.dart`：SQLite 事务、逐记录合并、删除标记、备份副本导入。
- `lib/editors.dart`：旅行设置和各类活动详情。
- `lib/home.dart`：路书、排序、预算和备份入口。
- `lib/sync.dart`：TLS、证书指纹配对、UDP 发现及同步确认。

同步使用系统 TLS 与 SHA-256 证书指纹校验，不自行实现加密算法。首次配对必须通过可信途径交换完整文本。本机凭据保存在应用私有数据库设置中，不进入路书备份。Windows 数据访问依赖当前用户目录的系统权限，不承诺抵御已获得用户权限的恶意软件。

## 环境与构建

本次使用 Flutter 3.47.7 / Dart 3.13.5、Visual Studio 2022、完整 OpenJDK 24.0.1、Android SDK 36、NDK 28.2.13676358。Flutter 与 Android 工具安装在项目 `.tools/`，不修改全局 PATH。

新电脑先安装 Visual Studio C++ 桌面开发组件和 JDK 17 以上，再将官方 Flutter 稳定版放入 `.tools/flutter`，Android SDK 放入 `.tools/android-sdk`。将本机 JDK 路径写入 `.local/java-home.txt`（不要把本机路径提交到 Git）。依赖版本由 `pubspec.lock` 固定。

JDK 必须包含 `bin/jlink.exe`，精简的 IDE 内置运行时可能缺少此组件。如果 Flutter 已配置过其他 JDK，使用 `Flutter.ps1 config --jdk-dir <完整JDK路径>` 更新 Flutter 设置。

```powershell
.\scripts\Flutter.ps1 pub get
.\scripts\Flutter.ps1 analyze
.\scripts\Flutter.ps1 test
.\scripts\Build-Windows.ps1
.\scripts\Build-Android.ps1
```

`Flutter.ps1` 在当前进程内设置工具路径，并使用目录联接准备 Windows 插件；无需为此全局打开 Windows 开发者模式。Windows 包包含运行所需文件与本机可用的 Microsoft VC 运行库。

当前锁定版本的 `file_picker` 仍使用 Kotlin Gradle 插件，Flutter 会提示未来版本的兼容性警告。当前构建不因此失败；升级 Flutter 时需同时核对该插件的迁移支持。

首次安卓构建生成独立正式签名：`.local/howdoi-release.jks` 与 `.local/release-signing.properties`。二者都被 Git 忽略。请另行妥善备份，后续覆盖升级必须保留该密钥；文件缺失一半时脚本会停止，不自动更换密钥。没有读取或修改 SPSir 签名。
