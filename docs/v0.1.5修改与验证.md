# HowDoI v0.1.5 修改与验证

日期：2026-10-15。版本：`0.1.5+6`，唯一来源为 `pubspec.yaml`。本轮只调整 Windows 旅行准备清单、卡片预算、版本显示与拖动手柄；安卓、SPSir、实际开支继续暂缓。

## 修改内容

- 关于主要显示 `v0.1.5`，不显示构建号；完整版本读取与更新比较不变，应用 EXE 和安装包保留 `0.1.5+6`。
- 左侧日期列表前新增“预备工作”，显示完成数量/总数量。清单独立于旅行日，未设置出发日期也能创建。输入名称按回车或点击加号即可添加；点击事项沿用右侧编辑面板，窄窗口使用编辑页。截止日期通过现有日历控件选择，备注可选。
- 清单支持勾选、取消完成、手动排序、删除。已完成事项置于底部可折叠区域，两组分别支持排序。离开前保护未保存编辑和已输入但尚未添加的名称。过期编辑版本拒绝写入，避免覆盖新保存内容。
- 准备清单保存在旅行记录的可选 `preparations` 数组中，旧旅行缺失此字段时为空清单。旅行设置保存保留该字段；修改出发日期不改截止日期。清单随旅行导出、导入副本和删除，沿用现有持久化与备份代码；无数据库迁移，无新依赖，备份协议仍为 3。清单作为旅行记录的一部分沿用旅行级更新规则。
- 行程卡片显示原币种预计预算，使用现有预算计算和币种小数规则。无条目不显示；0 正常显示；部分空金额标注“含未估算”；全部空金额显示“预算未估算”。跨日与住宿关联卡片标注“整条行程预算”，卡片展示不参与总计累加，不重复计费。
- 行程拖动手柄放入卡片内部，以卡片上下边界居中，保留 48×48 点击拖动区域并为正文预留空间。小时标题和备注展开不影响居中基准。原时间排序、未定时穿插和住宿/跨日关联规则不变。
