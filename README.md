# HowDoI

面向 Windows 与 Android 的旅行路书项目，当前处于需求与接口设计阶段，尚未实现应用。

计划支持离线行程编排、详细交通与住宿信息、跨时区时间、多币种预算及局域网同步。基础版本先实现路书；后续与独立的 SPSir 应用联动实际开支。
