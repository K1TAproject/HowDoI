# HowDoI

面向 Windows 与 Android 的离线旅行路书。0.1.0 实现手动行程编排、多币种预算、本地备份与局域网同步。

支持待安排清单、按天排序、详细交通与多晚住宿、跨时区时间、完成勾选和备注。当前只记录预计费用；SPSir 实际开支联动暂不实现。

使用入口、构建方式和验证范围：

- [使用说明](docs/使用说明.md)
- [开发与验证](docs/开发与验证.md)

本地运行产物位于 `dist/`（不纳入 Git）。真实 K70 跨设备同步仍需在目标手机与网络上验收。
