# HowDoI

离线旅行路书。当前发布版本为 Windows 0.1.1，重点完善行程录入与时间线；安卓新版适配暂缓。

支持灵活旅行日期、紧凑时间线、自动标题、详细交通与多晚住宿、当地票面时间、完成勾选和备注。当前只记录预计费用；SPSir 实际开支联动暂不实现。

使用入口、构建方式和验证范围：

- [v0.1.1 需求与交互设计](docs/v0.1.1需求与交互设计.md)
- [使用说明](docs/使用说明.md)
- [开发与验证](docs/开发与验证.md)

本地运行产物位于 `dist/`（不纳入 Git）。本版数据协议为 2，不与 Android 0.1.0 同步；支持导入旧格式备份。
